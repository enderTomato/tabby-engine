# ADR-006 · 液体实现路线

- **状态**：Accepted（**待重构**，见"后果"）
- **日期**：2026-11-14
- **影响范围**：`packages/physics/src/fluid.ts`、`packages/worker`；任务 T10，依赖 T07/T08
- **相关**：与 ADR-002 的粒子选型配套

## 背景

"流动液体"在模拟经营里承担三个完全不同的职责：

1. **管网/沟渠一维流** —— 供水管网、污水、地铁排水。玩家要能算流量、看压力，这是玩法
2. **地表格子水** —— 城市积水、洪水泛滥。要与地形高度耦合，是灾害系统的基础
3. **自由水面表现** —— 水花、瀑布、管道出口的视觉。纯观感

P05 要求三层都做，且模拟层必须确定性可存档。

## 可选方案

| 方案 | 适用层 | 移动端成本 | 确定性 | 评价 |
|---|---|---|---|---|
| SPH / PBF 粒子 | 表现层 | 高（1500 粒子 ≈ 6ms） | 好（固定步长） | 观感连续，但无法给出"流量"这种标量 |
| 浅水方程高度场 | 地表格子 | 中（512² 网格 ≈ 2ms） | 好 | 与地形天然耦合，可存档，但需要地形 |
| 元胞自动机通量法 | 地表格子 | 低 | 极好（整数运算） | 观感块状，需要后期平滑 |
| 圣维南简化 / 流量守恒 | 管网一维 | 极低 | 极好 | 纯标量计算，与粒子完全无关 |

## 决策

**分三层，当前只落地第三层，并明确接受返工。**

| 层 | 方案 | 状态 |
|---|---|---|
| 管网一维流 | 图上的流量守恒（节点 + 边容量） | ⬜ 未做，将复用 T16 的图结构 |
| 地表格子水 | 高度场 + 通量交换 | ⬜ 未做，**阻塞于 T08 地形** |
| 自由水面表现 | SPH-lite 粒子 | ✅ 已实现（`fluid.ts`） |

**为什么先做表现层**：它不依赖地形，能立刻验证 Worker + SAB + 渲染三层链路是否打通。这是一次**通道验证**，不是模块交付。

## 后果

### 正面

- 已经验证了：SAB seqlock 读、三档降级、粒子位置零拷贝上屏、低端机降档
- 粒子求解器本身可复用为瀑布、水花、管道喷口等纯表现元素，不会白写

### 负面（必须接受的代价）

1. **当前 `FluidSolver` 的公开 API 不能作为最终 API 承诺给用户。** 它的 `spawn(x,y,z,sx,sy,sz)` 是"喷粒子"，不是"设定流量"
2. 没有地形作为边界条件，水只会落在 AABB 底部，不会顺着坡流、不会在洼地积起来
3. 地形落地后，粒子的碰撞、吸收区、可视化全链路要重做一遍
4. 存档里不能存粒子状态（粒子是表现层，可丢弃），但**高度场必须存**——这部分设计还没开始

### 返工范围预估

| 模块 | 是否需要重写 |
|---|---|
| `fluid.ts` 求解器 | 保留，降级为表现层使用 |
| 吸收区（absorb zones） | 重写，改为高度场的水量转移 |
| Worker 协议 | 协议要带高度场分块，不只是粒子位置 |
| 渲染层点精灵 | 保留 |
| 新增高度场渲染（水面网格） | 全新 |

## 风险与缓解

| 风险 | 触发条件 | 缓解措施 |
|---|---|---|
| 用户基于当前粒子 API 做了扩展 | 半开源发布后 | **在 T10 正式收口前，`LiquidSystem` 不进 Public API**，只作 demo 内部使用 |
| 高度场与粒子双份内存 | 大规模洪水场景 | 高度场用 `Uint16` 分块按需加载；粒子只在可见区域生成 |
| 数值不稳定（CFL 条件） | dt 变大或网格变小时 | 通量法用整数运算并钳制单步最大流量；负高度直接钳到 0 |
| 存档体积爆炸 | 4096² 高度场 | 分块 + RLE + 只存 diff（与 T08 地形编辑共用方案） |

## 后续

本 ADR 在 T10 正式收口时需要**追加一条 ADR-00X「液体双层架构」**，明确模拟层与表现层的接口边界，并把本条的"待重构"状态改为 Superseded。
