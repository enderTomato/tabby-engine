# ADR-002 · 物理积分方式

- **状态**：Accepted
- **日期**：2026-11-14
- **影响范围**：`packages/physics`；任务 T09 T10 T11 T13

## 背景

自研物理引擎需要覆盖四类效果：流动液体、布娃娃、物理摆动、烟雾。它们对求解器的要求差异很大：

- 布娃娃要"看起来软"，不能穿地，几秒钟内必须稳定
- 摆动要周期性、可预测，风车转起来不能漂移
- 液体要连续、可注入可吸收，且能被 Worker 卸载
- 全部要在低端机上跑在 12ms 主线程预算内

模拟经营品类的物理只是**表现**，不是玩法核心（不像平台跳跃需要精确碰撞）。这决定了我们可以为"稳定与便宜"牺牲"精确"。

## 可选方案

| 方案 | 优点 | 缺点 | 移动端单点成本 |
|---|---|---|---|
| A. 显式 Euler | 最简单 | 长约束链会发散，布娃娃会炸开 | 低，但不可用 |
| B. 半隐式（Symplectic）Euler | 能量守恒好，适合刚体 | 仍需要质量矩阵与旋转积分 | 中 |
| C. Verlet 位置约束 | 无需求逆矩阵；距离约束天然稳定；断链/拉长可直接改 restLength | 不处理自旋惯量；软约束需要多次迭代 | **低**（单点约 40ns） |
| D. XPBD | 刚度与迭代次数解耦，参数物理意义明确 | 实现复杂；每个约束要维护拉格朗日乘子；调参需要经验 | 中高 |

## 决策

**分层选型，不统一用一个求解器：**

| 效果 | 求解方式 | 理由 |
|---|---|---|
| 布娃娃 / 绳索 | Verlet + 距离约束 + 斜撑 | 关节链稳定，断裂效果天然，成本最低 |
| 摆动 | Verlet 单摆（角度阻尼） | 周期可预测，风车不会漂 |
| 液体 | SPH-lite 粒子（密度松弛 + 粘性） | 无需网格化，Worker 友好，粒子数可线性降档 |
| 烟雾 | 无求解，纯粒子生命周期 + 浮力 | 视觉元素，不需要真实流体 |

**明确不引入 XPBD**：它的收益（刚度可控）在当前需求里用不到——布娃娃不需要精确布料，液体不走 PBD 路线。引入会让低端机迭代成本翻倍。

## 后果

### 正面

- 三种效果共用 Verlet 积分器与同一个障碍物碰撞查询，代码量小
- 迭代次数可按档位线性缩放（1 次 / 2 次），降档效果可预测
- 无矩阵求逆，无浮点病态问题，`NaN` 风险主要来自除零，容易拦截

### 负面

- 布娃娃无法正确表现自旋惯量：头比脚重这个物理事实需要靠 `invMass` 手工补偿，否则看起来"轻飘飘"
- 点状 Verlet 没有体积，贴地会塌成一张纸。当前用 `groundY + 0.12` 的伪半径糊过去（`ragdoll.ts`），这是近似不是解法
- 液体是粒子，不是连续场，无法直接支撑"管网一维流"这种模拟层需求（见 ADR-006）

## 风险与缓解

| 风险 | 触发条件 | 缓解措施 |
|---|---|---|
| 长链约束发散 | 绳索段数 > 16 且迭代不足 | 段数上限 + `maxSpeed` 钳制 + 每步位置修正 |
| 液体在低端机炸开 | 粒子数超档位上限 | `capacity` 硬上限 + `particleScale` 系数（0.4~1.0）随 GPU 家族调整 |
| 贴地穿透 | 高帧率下 dt 变小、位移变大 | `maxSpeed` 限制单步位移 ≤ 半径，天然防穿 |
| 数值不一致导致回放漂移 | 跨设备浮点差异 | 固定步长 + 固定迭代 + 显式步进顺序（见 T09 修正） |
